# teleprompt

I don't even know if this thing really needs a readme file.

It's a basic single page HTML app that you open locally. 
You give it a markdown file for playback.
That's it.

## Controls 
(all keyboard, shown in a fading HUD):
    
    - Space — play/pause auto-scroll
    
    - ↑ / ↓ — increase/decrease scroll speed
    
    - ← / → — jump back/forward to re-read or skip a line
    
    - + / − — adjust font size
    
    - M — mirror flip (for teleprompter glass rigs)
    
    - F — fullscreen
    
    - Esc — back to file picker
